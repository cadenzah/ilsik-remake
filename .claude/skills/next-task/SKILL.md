1. `.claude/docs/status.md` 를 읽고 "다음" 작업을 확인한다.
2. `.claude/docs/plan.md` 에서 해당 작업 항목만 찾아 범위를 확인한다.
3. 작업에 필요한 문서(formats/assets/rules)만 골라 읽는다.
4. 작업을 수행하고 검증한다.
5. plan.md 체크박스를 갱신하고, status.md 를 5줄 이내로 덮어쓴다. 새 사실은 해당 문서에 추가한다.
6. 의미 있는 단위로 git commit 한다 (original/, build/ 제외 확인).
