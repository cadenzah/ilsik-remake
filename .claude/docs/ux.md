# 원작 UI·진행 방식 분석 (U1, 2026-10-14)

근거: DOSBox 실기 관찰 (`tools/dosbox.py`, 캡처 build/dosbox/u*·v*·w*, 9장 「바하라무의 끝」 세이브 + 패배 뒤 1장 「전설」), EXE DS 문자열, UI 그림 파일.
[확정] = 화면으로 봄, [추정] = 정황만. 웹판 비교는 2026-10-14 코드 기준.

## 1. 전투 화면 구성 [확정]
- **화면 = 고정 640×480**. ECPMAI "tactics" 창틀(장식 테두리, 좌우 여신·악마 기둥) + 위 가운데 **장 제목 띠** (EXE DS:0x13aa 장 제목, 예 「전설」「바하라무의 끝」).
  맵 창 = (68,56)~(572,440) **504×384 = 9×8칸** (56×48). 확대·축소 없음. 맵 밖 HUD·버튼·턴 수 표시는 **없다**
- 유닛 위 **진영 표시** 13×13 (ECLIPSE.STA 13 파랑 웃는 얼굴 = 일행, 14 초록 = NPC, 15 빨강 찡그린 얼굴 = 적). 시스템 → 표기 로 켜고 끔
- **지금 차례 유닛 = 파란 모서리 괄호** (STA 1, 칸 크기). 행동을 마친 일행은 회색 (채도 빠짐) — 원작판 웹과 같음
- 마우스 커서 = 날개 지팡이 (STA 0). 마우스를 올려도 아무 정보 안 뜸 (칸 강조·지형 이름·유닛 카드 없음)
- **이동 범위 = 범위 밖을 어둡게** (STA 5 체크무늬 디더를 범위 밖 칸에 덮음). 범위 안 칸은 그대로. 범위가 화면 밖으로 넘쳐도 자동 스크롤 없음
- **공격 범위 = 화면 전체를 보랏빛으로 어둡게 (팔레트 조정), 사거리 칸만 원래 색**. 사거리 1 = 상하좌우 4칸 (STA 3 = 십자 모양 3×3칸 틀)
- 공격 대상 고르면 대상 칸에 **파란 둥근 사각 틀** (STA 2) + 확인창
- **전투 연출은 맵 위에서** (따로 전투 화면 없음): 공격자가 FIG 애니메이션 (예: 용 루이스 뛰어올라 불 뿜기), 맞는 쪽 붉게 번쩍, **빨간 숫자 = 피해** (대상 위, 예 29), 처치 시 반짝이며 사라짐.
  처치 뒤 **공격자 위 초록 숫자** (예 16) [추정: 얻은 경험치]. 마법은 MAG 이펙트 (파란 번개·노란 고리 등)
- 레벨업: STA 12 / OTH 3 「Level Up」 글자 그림, ECPLEV "level" 창 [추정: 레벨업 때 능력치 증가 창, 미관찰]
- 전투 시작 (첫 대화 뒤) 맵 왼쪽 위에 **「GO!! GO!!」 꼬마 그림** (OTH 4). 첫 클릭에 사라짐. 그 뒤 차례가 바뀌어도 다시 안 나옴 (9장에서 확인)
- 턴 수·"아군 차례"·"적 차례" 같은 알림은 **없다**. 적·NPC 차례에는 화면이 행동하는 유닛으로 툭툭 건너뛰며 따라감 (부드러운 이동 없음)

## 2. 창·메뉴 [확정]
모든 창 = 주황 제목 띠 + 크림색 바탕 + 장식 테두리 (comma 창틀), 버튼 = 주황 글자 버튼 (ECPBUT 0005). 창은 **누른 유닛 오른쪽 옆**에 뜬다. 모달 (창 밖 클릭 무시).
- **명령** (자기 차례 유닛 클릭): [마법] · 이동 · 전투 · 상황 · 시스템 (마법은 마법 있는 유닛만 [추정, DS:0x1fdf], 9장 루이스·아리크스는 4개)
  - 전투 = 제자리 공격: 사거리에 적이 없어도 공격 범위 표시로 들어감
  - 상황 = 작은 **인물기본자료** 창 (ECPBAS): 아이콘 4개 + 수치 (하트 생명 현재치 · 검 역량 · 날개방패 방어 · 회색 형상 [추정: 피로도, 00]) + 얼굴 아이콘 → 큰 인물기본자료 창 (정비 화면 상태창과 같은 내용·배치, 맵 가운데)
- **이동 뒤 명령**: [마법] · 전투 · **결정** (= 대기, 차례 끝) · **취소** (= 차례 시작 자리로 되돌리고 명령창 다시)
- 공격 대상 클릭 → **「전 투」 확인창 [결정][취소]** (DS:0x1f72. 마법은 「마 법」 0x1f6a)
- **시스템**: 알림 · 표기 · 음악 · 음향 · 조건 · 종료 (아래로 긴 창)
  - 알림 → 「알림전환」 [열기][닫기] (무엇을 켜고 끄는지 미확인. 피해 숫자·대화일 가능성)
  - 표기 → 확인 없이 바로 진영 표시 켜고 끔
  - 음악·음향 → [열기][닫기] [추정, 0x1fcc·0x1fd1]
  - 조건 → **승리조건 / 실패조건** 창 (파랑·빨강 소제목, 예 9장 「적군전멸」/「에릭 사망」). 문구 = DS:0xb55~0xc27 (적군전멸, ○○ 사망, 제국성문 도착, 용자벽화도착).
    **인물 이름이 대사와 다르다**: 에릭(=아리크스), 케이스·파치노·비비안리·크리스토퍼·시오우·하이로우·후니·파타라무 등 (옛 번역 이름 추정, 장별 대응 미추출)
  - 종료 → 「대기화면」 [결정][취소] = **정비 화면으로 돌아감** (전투 포기)
- 다른 유닛 클릭 (적·NPC·차례 아닌 일행) = 그 유닛 위에 작은 인물기본자료 창
- 「휴식」 [결정][취소] (DS:0x1f64): 빈 곳 오른쪽 클릭 (명령창 없을 때)
- **대화창** (ECPSPE "speak", 448×164): 크림색 바탕 + 녹색 장식 테두리, **초상 왼쪽**, 이름 파랑, 대사 검정 3줄, **글자가 한 자씩 찍힘**.
  **주고받기 = 위·아래 두 창** (A 위, B 아래, 둘 다 떠 있음), 단독 = 위 창 하나. 맵 위에 겹쳐 뜨고 맵은 말하는 사람 쪽으로 움직임. 클릭으로 넘김

## 3. 조작 흐름 [확정]
- 마우스 조작 (방향키는 반응 없음, 다른 키는 미시험). 왼쪽 = 고르기, **오른쪽 = 한 단계 뒤로**
- 행동 순서 = 라운드마다 순서 키 (rules·formats "전투 루프") 로 한 명씩. 페이즈 구분 없이 일행·적·NPC 가 섞여 차례가 온다. 경계 대기(상태 1) 적은 깨기 전까지 건너뜀 → 초반엔 일행만 계속 움직이는 것처럼 보임
- 차례가 오면: 화면이 그 유닛으로 이동 + 모서리 괄호. 범위는 바로 안 뜸. 그 유닛 클릭 → 명령창
  - 이동 → 범위 표시 → 칸 클릭 → 걸어감 → (화면이 유닛 중심으로) 이동 뒤 명령창. 범위 밖 칸 클릭 = 무시
  - 전투 → 공격 범위 → 대상 클릭 → 확인창 → 연출 → 차례 끝
- 오른쪽 클릭: 공격 범위 → 명령창 / 명령창 → 닫기 / 하위 창(시스템·상황) → 앞 창 / 아무 창 없음 → 「휴식」 확인
- 취소 가능한 곳: 이동 뒤 '취소' (자리 되돌림), 공격 대상 확인창 '취소'. 공격 뒤는 되돌릴 수 없음
- **화면 스크롤 = 창틀 클릭**: 왼쪽·오른쪽 기둥, 아래 띠를 누르면 그 방향으로 몇 칸 이동 (위 띠는 맨 위라 확인 못 함). 맵 가장자리에 마우스 대기·방향키·빈 칸 클릭은 스크롤 안 됨.
  그 밖엔 차례 유닛·행동 유닛으로 자동 이동. 미니맵 (ECPnn 마지막 그림, OTH 5 양피지 아이콘) 여는 길은 못 찾음
- 패배 (아리크스 사망): 패배 화면·메시지 없이 어두워졌다가 **1장 정비 화면 (초기 일행 3명, 등급 1)** 으로 (formats "기본 패배" 와 일치)

## 4. 게임 전체 틀 [확정 + 일부 formats 근거]
타이틀 (ECPTIT.FAT 창세 프롤로그 → 돌판 로고 → 두루마리 노인 + 메뉴: 지난흔적·유랑천하·게임종료)
→ 유랑천하 = 새 게임 / 지난흔적 = 「불러오기」 3칸 (칸 이름 = 저장한 장 이름) → **정비 화면**
→ 정비 화면 (읽기·기록·음악·종료, ⟺ 출전 편성, 행동 → 「여행계속」) — **저장·불러오기는 여기서만** (기록 3칸)
→ (지도 네 조각이 있으면 「성전으로 들어갈 수 있는 지도를 완성했다. 탐험계속?」 DS:0xaf5 [추정: 장 건너뛰기 질문])
→ **대륙 지도** (SCR 43 + 장소 이름표, 어두워졌다 밝아짐, 클릭 없이 수 초 뒤 넘어감)
→ 전투 맵 + 장 제목 띠 → 장 전 대화 (맵 위) → GO!! → 전투 (전투 중 장면은 조건 때) → 승리 → 장 후 대화 → 다음 장 정비 화면
→ 9장 뒤 「진로선택」 (comma 창, 암흑동굴·혼탁한호수·옛 신전) → … → 43장 승리 → 엔딩 (ECLIPSE3.FAT)
- 상점 없음. 장비 교체는 정비 화면의 도구 칸만 (formats "정비 화면 도구"). 전투 중 도구 사용 명령 없음 (명령창에 없음)
- 전투 중 저장 없음. 전투 중 '종료' = 정비 화면으로 (그 장 처음부터)
- 결과 창 (승리·패배 요약) 없음
- ECLIPSE.780 = 「SKC 구락부」 제작진 캐리커처 소개 14장 (어디서 여는지 미확인), OTH 7·8 = 전투 장면 스크린샷 (설명서·도움말 화면 추정)

## 5. 현재 웹판과의 차이
| 항목 | 원작 | 웹 원작판 | 웹 개선판 |
|---|---|---|---|
| 화면 틀 | 640×480 고정, tactics 창틀·장 제목 띠, 맵 9×8칸 | 캔버스 창 전체, 위 DOM 바 (장 제목·턴·버튼) | 같음 |
| 확대·스크롤 | 없음 / 창틀 클릭, 자동 따라가기 | 휠 0.5~2배, 끌기, 방향키 | 같음 |
| 진영 표시 | 머리 위 얼굴 아이콘 (표기로 끔) | 발밑 색 받침 (파랑·초록·빨강) | 같음 |
| 차례 유닛 | 파란 모서리 괄호 | 금색 테두리 깜빡임 | 차례 개념 없음 (페이즈) |
| 정보 보기 | 클릭 → 작은 창 (4수치) → 얼굴 → 큰 창. 마우스 올림 없음 | 마우스 올림 카드 (능력치·장비·지형) | 같음 + 피해 예측 |
| 명령창 | 이동·전투·상황·시스템 (+마법), 늘 전투 있음 | 이동·전투(적 있을 때)·취소 | 바로 범위, 적 클릭 = 이동+공격 |
| 이동 뒤 | 전투·결정·취소 (+마법) | 전투·대기·취소 | 공격·대기·취소 |
| 범위 표시 | 범위 밖 어둡게 (이동 디더, 공격 보랏빛) | 파란 칸 덧칠 / 빨간 칸 | 같음 + 위협 범위 |
| 공격 확인 | 대상 틀 + 「전 투」 결정·취소 | 대상 클릭 = 바로 공격 | 같음 |
| 피해 표시 | 빨간 숫자, 처치 뒤 초록 숫자 (경험치?) | 떠오르는 숫자 | 같음 |
| 턴 표시 | 없음 (시작 때 GO!! 그림) | 위 바 "턴 N · X 차례", 알림 | 같음 + 페이즈 알림 |
| 취소 후 | 자리 되돌리고 명령창 다시 | 자리 되돌리고 대기 상태 | 이동 범위 다시 |
| 휴식 | 빈 곳 오른쪽 클릭 → 「휴식」 | E·버튼·Esc → 「휴식?」 | 안 움직이면 자동 휴식, 턴 종료 버튼 |
| 시스템 | 알림·표기·음악·음향·조건·종료(→정비 화면) | 없음 (타이틀 버튼 → 타이틀) | 목표 창 (대본 있을 때) |
| 승패 조건 보기 | 시스템 → 조건 | 없음 | 목표 창 |
| 대화창 | 맵 위 두 칸 (위 A·아래 B), 한 자씩 찍힘 | 아래 한 칸, 초상 왼쪽, 한 번에 | 같음 |
| 키보드 | 쓰는 곳 못 찾음 | Esc·E·T·방향키 | 같음 |
| 마법·레벨업 | 있음 (명령·Level Up) | 없음 | 없음 |
| 저장 | 정비 화면 수동 3칸 | 장 클리어 자동 | 같음 |
| 패배 | 메시지 없이 1장 정비 화면으로 | 결과 창 [다시 하기·타이틀로] | 같음 |
| 승리 후 | 장 후 대화 → 다음 장 정비 화면 | 결과 창 [다음 장·다시 하기·타이틀로] | 같음 + 에필로그 |
| 대륙 지도 | 클릭 없이 자동 넘어감 | 2초, 클릭하면 넘어감 | 같음 (개선판 장 지도 따로) |

## 6. 미확인 (필요하면 DOSBox 로 더 보기)
알림전환의 대상, 마법 명령·마법 목록 창 (ECPMAG), 레벨업 창 (ECPLEV), 미니맵, 위 띠 클릭 스크롤, 스크롤 단위 칸 수, 진로선택·금괴 선택지 화면, 승리 직후 연출, 조건 창 이름의 장별 대응 (EXE 표 위치)
