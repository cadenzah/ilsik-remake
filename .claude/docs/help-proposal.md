## 1. 지금 무엇이 문제인가 (2026-11-07 도감 화면에서 확인)
1. **양.** 5쪽 42줄. 도감 화면 (640×450) 으로 약 2.5화면을 스크롤해야 끝난다. 줄마다 같은 굵기·같은 색의 「·」 목록이라 어디가 중요한지 보이지 않는다.
2. **도감 맨 밑에 묻혀 있다.** 동료·적·물건 목록 뒤에 붙어서, 진행할수록 (만난 인물이 늘수록) 도움말까지 더 멀어진다. 도감을 열고 도움말이 있는 줄도 모를 수 있다.
3. **중요도가 섞였다.** 「선두가 쓰러지면 패배」 와 「혜유가 질풍화를 차고 민첩 61 이상이면 두 번」 이 같은 무게로 나란히 있다. 처음 하는 사람에게 필요한 5가지와, 30시간 뒤에야 의미 있는 세부가 구분되지 않는다.
4. **쪽 나눔이 시스템 중심.** 「전투」 쪽 13줄에 계산 규칙·적 AI·도전 과제·상태 이상이 다 들어 있다. 「직업」 쪽에 고대 병기·정신과 마법이 있다. 플레이어가 궁금해하는 물음 (「왜 반격이 안 왔지?」) 으로 찾아갈 수 없다.
5. **한 줄에 조건이 너무 많다.** 「피로가 70을 넘었거나 생명이 ¼ 이하이거나 혼수·대기 상태면 되받지 못한다. 기사·포수·궁수·추전수의 공격과 마법은 되받지 않는다.」 — 조건 7개가 두 문장에. 표나 짧은 목록이면 한눈에 들어온다.
6. **용어가 흔들린다.** 화면은 「반격」 인데 도움말은 「되받아친다·되받지」. 「생명상해 마법」 과 「생명을 깎는 마법」. 「부하상태」 는 설명이 없다. 「적도 같다」 가 줄마다 되풀이된다.

## 4. 새 차례와 글 (지금 42줄 → 요약 8 + 핵심 약 22 + 자세히 약 18)
`[열림 계기]` 는 7원칙. 그림·표는 ◇.

**0. 처음이라면** [늘]
- 선두가 쓰러지면 진다.
- 운은 없다. 확인창의 숫자대로 들어간다.
- 맞고 살아남은 상대는 반격한다. 한 번에 못 잡을 상대에게 함부로 붙지 말 것.
- 지칠수록 약해진다. 움직이지 않고 차례를 마치면 쉰다.
- 위험 범위를 켜면 적이 닿는 곳이 보인다.

**1. 이기고 지기** [늘]
- 요약: 선두가 쓰러지면 패배. 호위할 인물이 있는 장도 있다.
- 핵심: 장마다 도전 과제 → 별 (목표 창). 가장 좋은 기록이 장 지도에 남는다.
- 자세히: 난이도는 적이 주는 피해를 바꾸고, 어려움에서는 적도 협공한다. 설정에서 언제든.

**2. 치고 받기** [늘] 양편 공통
- 요약: 근접 공격을 맞고 살아남으면 반격한다. 반격은 몇 번이든 줄지 않는다.
- ◇ 표 「반격이 없는 때」: 반격하는 쪽이 피로 70 초과 · 생명 ¼ 이하 · 혼수/대기 │ 공격이 기사 · 포수 · 궁수 · 추전수 · 마법
- 핵심: 운은 없다 / 확인창에 「반격 −N」 이 미리 보인다.
- 협공 [flank 플래그 또는 2장]: ◇ 칸 그림. 대상 옆에 같은 편이 붙어 있으면 한 명마다 물리 피해가 오른다 (셋까지). 확인창 「협공」.
- 전력 공격·방어 [2장]: 전력 = 피해 크게, 피로도 크게 (확인창에 보임). 방어 = 움직이지 않은 차례에, 다음 차례까지 물리 방어 ↑, 대신 쉬지 않음.

**3. 움직이기** [늘] 양편 공통
- 요약: 적 바로 옆 칸에 들어가면 이동이 멈춘다 (통제 영역).
- ◇ 칸 그림 (멈추는 칸 빨강)
- 자세히: 날개 있는 유닛·도둑은 멈추지 않는다. 혼수에 빠진 유닛 옆에서도 멈추지 않는다.

**4. 지치고 쉬기** [늘] 양편 공통
- 요약: 피로가 쌓일수록 공격과 방어가 함께 떨어진다. 움직이지도 치지도 않고 차례를 마치면 쉰다 (생명·피로 회복).
- ◇ 작은 표 「피로가 쌓이는 것」: 공격·반격 4~8 / 이동 한 칸에 1 / 마법 목록의 수 / 맞기만 하면 0
- 핵심: 피로 70을 넘으면 반격 못 함. 적도 70을 넘거나 생명 ¼ 이하면 그 차례에 쉰다 (머리 위 「휴식」).
- 자세히: 부하상태가 낮을수록 공격·마법 피로가 많다 / 레벨업하면 0, 생명회복 마법으로도 준다 / 지금 피로 + 마법 피로가 90을 넘으면 그 마법은 못 쓴다.

**5. 직업마다 다른 공격** [그 직업을 만났을 때 줄마다]
- ◇ 칸 그림 셋: 궁수·추전수·포수 = 가로세로 일직선 / 포수 = 맞은 칸 둘레까지 (같은 편도!) / 기사 = 고른 칸 둘레의 적
- 생명상해 마법은 대상의 정신이 높을수록 덜 든다 → 방어만 높은 적에게.

**6. 약점 찌르기 (상성)** [첫 약점·내성 또는 3장] 양편 공통
- 요약: 생명상해 마법과 활은 대상에 따라 더 들거나 덜 든다. 확인창에 「약점」「내성」, 카드에 까닭.
- ◇ 표 (대상 │ 약점 │ 내성), 맞선 계열 고리 그림 (물↔불, 바람↔땅, 빛↔어둠):
  | 대상 | 약점 | 내성 |
  |---|---|---|
  | 나는 유닛 | 활·바람 | 땅 |
  | 마법 쓰는 유닛 | 제 계열과 맞선 계열 | 제 계열 |
  | 중갑 기사 | 땅 | |
  | 불사족 | 빛 (크게)·불 | 어둠 |
  | 마족 | 빛 | 어둠·불 |
  | 용족 | 물 | 불 |
  | 해족 | 바람 | 물 |
  | 기계 | 바람 | |
  종족 줄은 그 종족을 만난 뒤 열린다 (빙마녀 줄은 만나기 전엔 없음).
- 자세히: 칼·창 같은 다른 물리 공격과 다른 마법에는 상성이 없다.

**7. 적의 속셈** [늘, 줄마다 계기]
- 요약: 적은 쓰러뜨릴 수 있는 대상과 회복 마법을 쓰는 대원을 먼저 노린다.
- 핵심: 경계 중인 적은 가까이 가거나 치면 깬다 (위험 범위에 청록) / 부대는 발을 맞춰 오다가 하나가 싸우면 모두 달려든다.
- 자세히: 대기 중인 적은 정해진 때까지 맞아도 움직이지 않는다 / 보스는 그 차례에 닿는 상대가 있을 때만 움직인다 / 지친 적은 일행이 닿지 않는 곳으로 물러나 쉰다.
- 상태 이상 [첫 중독·혼수]: 중독 = 3차례 동안 차례마다 생명 ⅓ 잃음 / 혼수 = 3차례 동안 아무것도 못 함.

**8. 강해지기** [늘]
- 요약: 경험치 100이면 레벨업. 레벨 높은 적, 마무리 일격일수록 많이 받는다.
- 핵심: 이긴 장에서 쓰러진 대원은 그 장의 성장을 잃고 다음 장을 지친 채 시작한다 / 승급은 바로 받거나 정비 화면에서 나중에 (떨어지는 능력치도 있다).
- 자세히: 출전 안 한 동료도 조금 받는다 / 늦게 합류한 동료는 일행 레벨 근처로 / 전직·교체해도 레벨 이어짐 / 오르는 능력치는 판마다 정해져 다시 해도 같고, 오래 덜 오른 능력치는 하나 더 오른다.
- 숨은 것 [발견 뒤]: 고대 병기 4종 (제관·사바카 방어를 뚫음, 마법엔 안 들음) / 혜유 질풍화 (민첩 61 이상이면 한 차례 두 번).

## 5. 작업 크기 (반영할 때)
1. help.ts 데이터 모양 바꾸기: `{ key, title, both?, summary, figure?, core[], more[], unlock? }[]`, 줄 단위 `unlock`. 글은 위 4절. tips-proposal 카드는 `summary` 를 가리킨다.
2. 그림 렌더러: 5×5 칸 캔버스 (타일 한 종 + 유닛 아이콘 + 칸 칠하기). 그림 4개 + 상성 고리.
3. 도감 탭 [인물][물건][도움말], 도움말 = 목록 + 본문. 스타일 (줄 간격·금색 용어·「양편 공통」 표식·「자세히」 접힘).
4. 전투 창 rulesWin: 같은 데이터, 「지금 관련된 주제」 먼저.
5. 열림 계기: Progress 의 seen (종족·인물)·판 플래그·장 번호. 원작판은 해당 없음 (도움말은 개선판만).
6. 확인: 처음 판 (Progress 없음) 에서 스포일러 없음, 끝낸 판에서 전부 열림, 640×450 에서 주제 하나가 스크롤 없이 들어가는지.
