# 원작판 / 개선판 구조 (검토안, 2026-10-12)

목표: 같은 엔진 위에서 **원작판**(원작 재현)과 **개선판**(장면 재구성·현대어 대사·재설계 시스템)을 모두 실행. 공통 부분을 최대한 같이 쓴다.

## 결론: 브랜치가 아니라 한 코드베이스 안의 "에디션"
- 브랜치 두 개 (original / remake) 는 추천하지 않는다. 엔진 수정(렌더·입력·버그)이 두 브랜치에 계속 옮겨져야 하고,
  지금처럼 main.ts 한 파일에 섞여 있으면 매번 충돌한다. 브랜치는 지금처럼 기능 단위로만 쓴다.
- main 하나에 `src/editions/original`, `src/editions/remake` 를 두고, 타이틀 화면(또는 `?ed=`)에서 고른다.
  배포도 하나 (같은 URL 에서 두 판 선택). 에디션 코드는 dynamic import 로 나눠, 고른 판만 받는다.

## 나누는 선
| 층 | 공통 (core) | 에디션별 |
|---|---|---|
| 자원 | 원작 추출물 `public/assets` (맵·스프라이트·초상화·효과음·데이터 표) | 개선판의 추가 자원 (새 맵 배치, 새 초상화가 생기면) |
| 엔진 | 캔버스 렌더, 카메라, 입력, 이동 경로·범위 계산, 애니메이션, 대화 재생기, 메뉴 UI 틀, 세이브 저장소 | — |
| 전투 규칙 | 규칙 **인터페이스** (`Rules`) | 피해·명중·반격·지형 보정, 행동 순서 (원작: 민첩 키 개별 순서 [확정 공식] / 개선: 재설계), 경험치·레벨업, 마법·피로, 전직 |
| AI | 탐색 도우미 (도달 범위·공격 칸) | 대상 고르기·행동 결정 (원작: 부대 상태 규칙 + 원작 AI 재현 / 개선: 재설계) |
| 캠페인 | 캠페인 **그래프 실행기** (장 노드·분기·조건·플래그·합류/이탈 처리) | 그래프 데이터 자체 (원작: EXE 추출 그대로 / 개선: 재구성한 그래프) |
| 이야기 | 장면 재생 형식 (화자·줄·분기) | 대사 내용 (원작: dialogue.json 원문 / 개선: 새로 쓴 대사) |
| 세이브 | 저장 형식 틀 | 에디션별 구역 (`eclipse:original:*`, `eclipse:remake:*`), 서로 섞이지 않음 |

핵심은 **캠페인을 코드가 아닌 데이터 그래프로** 만드는 것. 지금 `scenes.json` post 단계(join·leave·swap·routes·flag·item)와
`battles.json` (route·cond·turn) 이 이미 그 재료다. 원작판은 이것을 그대로 쓰고, 개선판은 같은 형식으로 새 그래프를 쓴다.
장면 재구성(장 순서 변경, 새 분기, 장 합치기)이 코드 수정 없이 데이터로 가능해진다.

## 개선판 데이터를 어디에 두나
- 원작 추출물은 지금처럼 gitignore (저작권). 개선판은 우리가 쓰는 것이라 저장소에 커밋: `content/remake/` (campaign·scenes·lines·battles 덮어쓰기).
- 개선판 대사는 새로 쓴 문장만 저장. 원작 줄을 그대로 쓰는 곳은 줄 번호(`line: 123`)로만 참조 → 원작 문장이 저장소에 들어가지 않는다.
- 배치 변경은 원작 레코드 위에 덮어쓰기(`records["12-1"]` 의 그룹 추가·교체)로. 맵 자체는 원작 그대로 공유.

## 결정 (2026-10-12 사용자)
- 이 구조로 진행. 공통 코드를 최대한 많이. 원작판 = 원작 로직·메커니즘, 개선판 = 원작 바탕으로 개선한 분리된 메커니즘
- 판 선택 = 런타임. 원작판은 원작 그대로, 편의 기능(위협 범위·피해 예측·이동+공격 한 번에 등)은 개선판만
- 개선판 대사·데이터(`content/remake/`)는 커밋. 저장소는 나중에 공개 예정
- 진엔딩 구조(세 루트가 다른 조각 → 숨은 장) 좋다고 함. "다른 길로" 때 능력치·장비를 얼마나 가져갈지는 미정 (아래 답변 참고)

## V1 엔진 분리 — 완료 (2026-10-12)
```
src/main.ts            ?ed=original|remake (기본 개선판) → 판 dynamic import → core/battle.boot
src/core/   data · unit (Unit·Pos·equippedStats [확정]) · grid (이동·경로·사거리) · edition (Edition 인터페이스)
            state (S·Mode·unitAt/alive/isNpc/canCommand) · render (캔버스·카메라) · ui (DOM 오버레이)
            battle (초기화·동작·승패·턴 루프·플레이어 명령) · input (마우스·키보드) · campaign (플래그·장면 줄) · stage
src/editions/original/   rules.ts (피해 [근사]·사거리 [추정]·순서 키 orderKey [확정]·order) · ai.ts (planFor [근사]) · index.ts
src/editions/remake/     index.ts — 원작판을 펼쳐 order(페이즈제)·features 만 덮어쓴다
```
- Edition = { rules{damageRange, rollDamage, weaponRange}, order(units, round) → Unit[][], planFor, features{threat, forecast, quickAttack} }
- 턴 루프 `battle.runRounds`: 라운드마다 턴 시작 이벤트 → order() 단계 차례로. 일행 단계는 플레이어 (단계 유닛이 다 행동하거나 E), 나머지는 AI.
  order 에는 숨김(reserve)·사망 유닛도 넘기고 실행 때 건너뛴다 → 단계 중에 나타난 부대도 그 라운드에 움직인다 (원작 순서표와 같음)
- 원작판: 한 명씩. 차례 유닛 칸 깜빡임 → 눌러 명령창(이동/전투/취소), 버튼 = "휴식" (Esc·우클릭도: 이동 되돌림 → 휴식?). 위협 범위 버튼 숨김, 피해 예측·적 클릭 이동+공격·공격 가능 적 표시 없음 (features.commandFirst)
- 개선판: 페이즈제 [일행, NPC, 적], 편의 기능 켬, 이동·공격 없이 마치면 자동 휴식 (features.autoRest). 알림은 단계가 2명 이상이면 페이즈마다, 아니면 라운드 첫 단계에 "턴 N"
- `content` (개선판 대사 덮어쓰기 경로)는 S3 에서 대본 형식과 함께 추가
- 확인: 두 판 1장 자동 진행 클리어 (원작판 12턴, 개선판 8턴), 원작판 7장 NPC 끼어들기, 재시작, 개선판 피해 예측, `pnpm build`
- 테스트 팁: 브라우저 패널이 숨겨지면 rAF 가 멈춰 걷기 애니메이션이 멈춘다 → 로드 직후 `requestAnimationFrame = cb => setTimeout(() => cb(performance.now()), 16)`

## 타이틀 메뉴 — 완료 (2026-10-12)
- `src/core/title.ts` 원작 메인 메뉴 재현 (formats.md "메인 메뉴"): 640×480 통째 확대, 로고 번쩍+천둥 → 두루마리 노인 + 돌 창틀. 창 안 = 유랑천하(새로 시작)·지난흔적(이어하기) 원작 버튼 그림 + 장 선택·제작진·판 선택(같은 모양 글자). 제작진 = ECPPLANE 0·1 + 팬 게임 고지 (원작 게임종료 화면 흐름). 로고 연출은 탭마다 한 번 (sessionStorage)
- `src/core/save.ts` 판마다 localStorage `eclipse.progress.{original|remake}` = {next 이어하기 장, cleared 장 선택 목록, flags}, 마지막 판 `eclipse.edition`
- 새로 시작 = next 를 1장으로 (클리어 기록은 유지). 이어하기 = next 장. 장 선택 = 클리어한 장 다시 하기 (진행 저장 안 함)
- 승리 화면: 다음 장 (전투 순서표 `nextStage`, 9장 뒤 진로 선택 3택 = Edition.routeLabels) / 다시 하기 / 타이틀로. 상단 "타이틀" 버튼 (확인 후 새로고침)
- 원작판 진로 문구는 그래픽이라 미판독 → "첫째/둘째/셋째 길", 개선판은 S2 제안 1 문구
- 아직 없음: 장 사이 일행 합류·이탈·소지품 (다음 장도 scenes.party 처음 일행), 전투 중 저장. → U3
- `?ed=..&stage=N` 이면 타이틀을 건너뛴다 (스모크 테스트 경로 그대로)
