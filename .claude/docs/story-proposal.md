# 스토리 평가와 수정 제안 (S2)

근거: `story.md` (S1). 승인된 항목만 반영한다. 원작 대사는 유지하는 것이 기본이고, 아래 제안은 대부분 **추가** (대사·표시·조건 노출) 이다.

## 총평
- 잘 된 점: 8장 레스다의 죽음과 유언이 37장 정체 공개까지 이야기를 끈다. 페니(비왕의 딸) 이야기는 시작·전환·마무리가 다 있다.
  38장 소피아는 플레이 방식(죽이느냐, 마지막까지 남기느냐)으로 결말이 갈려 SRPG다운 연출이다.
- 약한 점 4가지
  1. **선택과 조건이 보이지 않는다.** 진로 선택은 정보 없는 3택이고, 결과가 달라지는 조건 4개(9장 금괴, 19장 용왕 생존, 27장 흑기사, 38장 소피아)에 복선 대사가 없다.
  2. **중반이 비어 있다.** 10~35장 루트 전용 장은 평균 6줄이고 1~2줄짜리 장이 7개다. 루트마다 이야기 구멍이 있다 (B: 채스가 설명 없이 합류, A: 크란이 37장에야 처음 나옴).
  3. **동료가 많은데 말이 없다.** 일행은 13~14명인데, 합류한 뒤 다시 말하는 동료는 카론·프래트·페니·혜유 정도다. 루트 전용 동료 9명 중 합류 뒤 다시 말하는 것은 리사·유니스(한두 번)뿐이다.
  4. **큰 설정이 한 번에 쏟아진다.** 사바카 전설(26장)과 쌍둥이 정체(37장)를 독백 한 번으로 설명하고, 엔딩에 나오는 고대 병기 4종 중 이야기에서 다룬 것은 빛의 갑옷뿐이다.

## 6번 상세: 클리어 후 다른 루트 열기
- 현재 원작: 9장 뒤 고른 루트로 28~29장만 진행. 다른 루트 전용 장 14~15개(A 8 / B 7 / C 5)는 처음부터 다시 9장까지 와야 볼 수 있다.
- 제안 (개선판):
  1. **분기점 저장**: 9장 직후(진로 선택 직전) 상태를 자동 저장. 엔딩 뒤 "다른 길로" 메뉴로 그 상태에서 다른 루트를 바로 시작.
  2. **장 지도**: 43장을 루트 갈래로 그린 화면. 가 본 장·안 가 본 장, 찾은 조건 사건(흑기사·수호자·루이스 귀환·소피아 합류)을 표시 → 무엇을 놓쳤는지 보여 준다.
  3. **장 다시 하기**: 클리어한 장은 장 지도에서 골라 다시 플레이 (기록용, 본편 진행에는 영향 없음).
  4. (선택) **이어하기 강화**: 두 번째 루트부터 레벨·장비 일부를 이어받기.
- 재구성까지 하기로 했으므로 더 나아간 안: 세 루트가 사건의 다른 조각을 맡게 재구성 (A 크란과 정체, B 소피아와 제관의 세뇌, C 고대 병기와 수호자).
  세 루트를 다 보면 숨은 장(예: 레스다의 과거, 크리스도프 반란의 밤)이 열리는 진엔딩 구조. 이 경우 1~3은 필수가 된다.
