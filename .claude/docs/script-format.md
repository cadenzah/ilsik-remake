# 개선판 대본 형식 (S3, 2026-10-13 사용자 확정 — 5절 4가지 모두 추천안)

목표: S2 제안 1~15 를 개선판에 쌓을 그릇. 원작판은 지금처럼 `scenes.json`(EXE 추출)을 그대로 쓰고,
개선판은 `content/remake/` 의 대본이 원작 장면을 **장면 단위로 덮어쓰거나 새 장면을 더한다**. 엔진(대화 재생기·캠페인 실행기)은 공통.

## 1. 파일과 읽는 방법
```
content/remake/
  chapters/01.ecs … 43.ecs   장마다 한 파일: 장 카드·보조 목표·전투 전/중/후 장면 (없는 장 = 원작 그대로)
  banter.ecs                 동료 한마디 풀 (제안 8)
  epilogue.ecs               에필로그 (제안 15)
  names.json                 화자 이름 → 유닛 번호, 표기 통일 (제안 13: 아크리스→아리크스 등)
```
- 확장자 `.ecs` = 줄 단위 글 (JSON 아님). 대사를 쓰고 고치기 쉽고 git diff 가 읽힌다.
- 웹은 Vite `import.meta.glob('…/*.ecs', { query: '?raw' })` 로 읽어 (`src/editions/remake/index.ts`) `src/core/script.ts` 가 판을 불러올 때 해석 (빌드 도구 추가 없음). 문법 오류 = 게임 화면에 `파일:줄: 이유` (ScriptError).
- 저작권: 원작 문장을 그대로 쓰는 줄은 **원작 줄 번호만** 적는다 (`=123`). 저장소에 들어가는 글은 새로 쓰거나 현대어로 고쳐 쓴 문장뿐.

## 2. 문법 (예: 3장)
```
# 3장 — 주석은 # 로 시작
card 지하 신전 | 소피아를 데려간 자들을 쫓는다          ← 장 카드 (제안 4): 장소 | 한 줄 목표
goal 금위대장을 지켜 낸다 keep alive=1.0               ← 보조 목표 (제안 2). keep = 조건이 깨지면 ✗, ok = 조건이 맞으면 ✓, 조건 없으면 표시만

== pre                                ← 전투 시작 장면. 원작 pre 장면(0:3)을 통째로 대신한다
카론: 이 아래가 지하 신전입니다. 발밑을 조심하세요.
레스다: =33                           ← 원작 33번 줄을 그대로 (화자만 지정)
아리크스: =34 ~ 소피아는 반드시 되찾는다.   ← 원작 34번 줄을 고쳐 씀 (~ 뒤가 새 문장, 원작 번호는 대조용 기록)
페니|출전: 저기, 뭔가 움직였어!         ← 화자 대체 (제안 11): 페니가 없으면 출전 동료 중 하나, 그래도 없으면 줄 생략
-: (멀리서 종소리가 울린다)            ← 초상화 없는 줄

== post route=B                      ← 전투 후. 조건이 붙은 장면은 조건이 맞을 때만
아리크스: …
? 금괴 조각을 준다 | 주지 않는다      ← 선택지 (9장). 아래 블록이 고른 쪽만 재생
  > 1
  아리크스: 받으시오.
  do give 168, take 180
  > 2
  아리크스: 아직은 안 됩니다.

== turn 5 route=A                    ← 전투 중 (제안 12): 턴 시작
루이스: 매복이다!

== keep post                          ← 원작 장면을 그대로 두고 앞/뒤에만 덧붙이고 싶을 때: keep 블록 위치에 원작 장면이 재생된다
```
- 블록 = `== 시점 [조건…]`. 시점: `pre` · `post` · `turn N` · `troop N` (부대 N 이 움직이기 시작할 때, 원작 상태 0 전환) · `dead 유닛` · `hp 유닛 <30%` · `win` · `lose`.
- 조건 (모두 AND): `route=A|B|C` · `flag=npc19` / `!flag=…` · `item=168` / `!item=…` · `in=페니` / `!in=…` (출전 중) · `party=페니` / `!party=…` (일행에 있음) · `alive=부대.번호`.
- 부대 번호 = 0 일행, NPC 가 있으면 1 = NPC, 그다음부터 원작 적 무리 순 (battle.ts placements). `tools/ecs_draft.py` 가 이름으로 풀어 보여 준다.
- 캠페인 동작 `do …` 은 지금 `PostStep` 과 같은 말: `join 유닛` · `leave` · `swap a b` · `give`/`take 도구` · `flag 이름` · `promote`. 개선판에서 장 순서를 바꾸는 `goto 장` 도 같은 자리에.
- 화자는 이름으로 쓰고 `names.json` 이 번호로 바꾼다. 같은 이름의 다른 유닛(아리크스 0/1, 아티스 25/26)은 지금 일행에 있는 쪽, 명시하려면 `아티스#26`.

## 3. 덮어쓰기 규칙
- 개선판 장 파일에 `== pre` 가 있으면 원작 pre 장면 전체를 버리고 이것을 쓴다. 없으면 원작 그대로 (단, 표기 통일·현대어는 원작 줄에 적용할 수 없으므로 **결국 모든 장을 옮겨 쓰게 된다** — S3a 13번 작업).
- 줄 단위 패치(“원작 N번째 줄 뒤에 끼우기”)는 두지 않는다. 원작 장면 순서가 바뀌면 깨지기 쉽고, 현대어로 다듬으면 어차피 전부 손대기 때문. 대신 `keep` 으로 원작 장면 앞뒤 덧붙이기만 허용.
- 전투 후 캠페인 단계: 개선판 장 파일에 `do` 가 하나라도 있으면 그 장의 원작 post 단계(합류·이탈·소지품)를 모두 대신한다 → 재구성(장 순서·합류 시점 변경)이 데이터만으로 가능. 없으면 원작 단계 그대로.
- 진로 선택(제안 1)·장 순서(제안 6 진엔딩): `content/remake/campaign.json` 에 전투 순서표와 진로 선택 문구. 대본 파일과 분리 (구조 데이터라 JSON).

## 7. 화자 대체 규칙 (제안 11, S3a 적용)
- `이름` 하나 = 출전 여부와 상관없이 그 인물이 말한다 → 줄거리·인물 고유의 줄 (페니의 아버지 이야기, 크란의 설명, 합류 장면 등). 이야기상 일행은 함께 다니고 출전은 전투 편성일 뿐이라고 본다.
- `이름|출전` = 그 인물이 출전하지 않았으면 출전 동료 중 하나가 대신 → 상황 해설·작전·위로·설득처럼 누가 해도 되는 줄. 대신 말해도 어색하지 않게 다른 인물 이름을 부르지 않도록 고쳐 씀 (31·34장).
- `이름?` = 출전하지 않았으면 그 줄을 뺀다 → 인물 성격이 묻은 농담·감탄 (프래트·애슬 농담, 카론의 "……!").
- 출전 판정: 전투 전·중 = 살아 있는 출전 대원, 전투 후(post) = 쓰러진 대원도 포함 (원작은 쓰러져도 일행에 남음).
- 1~16장은 일행 수 ≤ 출전 칸이라 대체가 필요 없다. 루트 A 17장, B·C 19장부터 일행이 출전 칸보다 많아진다.
