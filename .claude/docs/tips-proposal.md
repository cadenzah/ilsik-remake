# 개선판 새 시스템을 대화로 드러내기 (제안, 2026-11-07 — 아직 반영 안 함)

사용자 요청: 개선판에 넣은 새 시스템이 진행 중 대화로 자연스럽게 드러나게. 지금은 전투 메뉴 「도움말」·도감 (core/help.ts RULE_PAGES) 에서만 알 수 있다.
근거: 장별 첫 등장 = battles.json 루트 순서 (A 1~11·16·19·17·18·20·22·26~29·36~43, B 1~9·12·14~16·19·23~26·30~32·36~43, C 1~9·13~16·19~21·26·33~43), 대본 틀 = script-format.md, 화자 말투 = script-format.md 8절.

## 1. 원칙 — 어색하지 않게
1. **일이 벌어진 그 순간에, 한 번만.** 규칙 설명을 장 시작에 몰아 두지 않는다. 처음 반격을 받았을 때, 처음 약점을 찔렀을 때처럼 플레이어 눈앞에 그 일이 있을 때 한 줄. 판마다 한 번 (판 플래그 `tip:키`, 레스다 회상 `recall:` 과 같은 방식)
2. **인물 한 줄 + 안내 카드 한 장** (2026-11-07 사용자 의견으로 고침 — 처음 안은 "세계의 말로" 만이었는데, 그것만으로는 규칙이 분명히 전해지지 않는다).
   - 인물 대사는 세계의 말로, 짧게. 「버튼·메뉴·확인창·%」 를 쓰지 않는다. 분위기와 "왜 신경 써야 하는지" 를 맡는다
   - 바로 뒤에 **안내 카드**: 제목 (시스템 이름) + 두세 문장. 플레이에 필요한 만큼만 쓴다. 무엇이 일어나는지, 언제 일어나지 않는지, 어디에서 미리 보는지 (확인창 「반격 −N」 같은 화면 이름은 여기서 쓴다). 화면에 이미 보이는 기준선 (피로 70·생명 ¼) 은 쓰고, 화면에 안 보이는 내부 계수 (×1.5·0.4 등) 는 쓰지 않는다 — help.ts 와 같은 수준
   - 카드 문장은 도움말 (help.ts RULE_PAGES) 과 **한 곳에서** 가져온다 (키마다 도움말 줄을 가리키거나 카드 글을 help.ts 에 둔다). 고칠 때 두 곳이 어긋나지 않게
   - 카드 아래 「도움말에서 더 보기」 (그 쪽이 열림)·「닫기」. 대화와 한 흐름 (대사 → 카드 → 닫으면 조작으로), 따로 두 번 멈추지 않는다
   - 화자가 없으면 (출전 안 함·그 장에 없음) **카드만** 낸다. 규칙을 아는 일이 누가 출전했는지에 달리지 않게. 인물 줄은 덤
   - 설정은 둘로: 「이야기 속 안내」 (인물 줄)·「안내 카드」. 두 번째 판은 카드만 끄는 사람이 많을 것
   - 본 카드는 도움말 쪽에 모인다 (전투 메뉴 「도움말」 맨 앞 「안내 기록」, 본 순서대로). 놓친 카드를 다시 읽는 곳
3. **아는 사람이 말한다.** 검술·진형은 레스다 (1~8장, 9장 뒤는 「레스다 (회상)」), 술법·기운·피로는 카론 (늘 높임말, 이야기의 길잡이), 자기 일은 당사자 (활·날개는 페니, 날개 달린 몸은 루이스, 불은 애슬, 얼음은 리사, 고대 병기는 크란). 출전하지 않았으면 다음 후보, 아무도 없으면 넘기고 다음 기회에
4. **흐름을 끊지 않는다.** 적 차례 중에 생긴 일은 다음 아군 차례 시작에 말한다. 한 차례에 안내 하나 (줄 + 카드), 한 장에 셋까지 — 1장은 처음 겪는 것이 몰려서 (wake·counter·zoc·flank·promo) 셋을 넘으면 다음 장으로 미룬다. 장 시작 대화·목표 창과 겹치지 않게
5. **원작 이야기를 덮지 않는다.** 원작 장면은 그대로 두고 덧붙이기만. 장 대본에 `do` 를 쓰면 그 장의 원작 전투 후 단계 (합류·아이템) 를 통째로 대신하는 함정이 있으니 (script.ts ownsSteps) 안내 줄은 장 대본이 아니라 따로 둔다
6. **끌 수 있게.** 설정 「이야기 속 안내」 (기본 켬). 한 번 엔딩을 본 판 기록 (Progress) 이 있으면 기본 끔을 묻는다. 원작판은 없음

## 2. 소개할 것과 하지 않을 것
대화로 소개할 것 (규칙이라 몰라서 손해 보는 것) 과, 화면이 스스로 말하거나 바깥 설정이라 대화에 안 맞는 것을 나눈다.

## 3. 그릇 — `content/remake/tips.ecs` (recall.ecs 를 넓힌 것)
```
# 키 · 화자 후보 (앞에서부터, 출전·생존한 일행) · 대사. 화자마다 다른 대사를 줄 수 있다
@ counter
레스다: 맞고도 버틴 놈은 그대로 되받아친다. 한 번에 끝낼 수 없는 상대라면 함부로 붙지 마라.
카론: 맞고도 버틴 자는 곧장 되받아칩니다. 한 번에 끝낼 수 없다면 붙기 전에 한 번 더 생각하시지요.
@ arrow when=foe     ← 적 활이 아군 비행을 맞힘
루이스: 아야… 날개 달린 몸엔 화살이 아프게 박혀요.
@ arrow when=ally
페니: 날개 있는 놈은 내 화살을 못 피해!
```
- 엔진: `tip(key, ctx)` — 판 플래그 `tip:키` 가 없으면 후보 중 첫 출전·생존 대원 (레스다는 9장부터 회상) 으로 한 줄 (「이야기 속 안내」 켜짐·화자 있을 때) → 안내 카드 (「안내 카드」 켜짐), 플래그를 세우고 「안내 기록」 에 남긴다. 적 차례면 줄을 쌓아 두었다가 아군 차례 시작에. 한 차례 하나·한 장 둘
- 부르는 자리 (조사): 반격 = battle.ts attack 의 counterAct, 약점·내성 = castSpell 의 spellResult 뒤·attack 의 strike 뒤 (rules.affinity), 협공 = 공격 실행 때 rules.flank, 통제 영역 = 대원 고를 때 reachable 을 zoc 끄고 한 번 더 구해 비교, 피로·적 휴식 = 아군 차례 시작 (playerStep), 승급 = showLevelUp 뒤 (recall 자리), 쓰러진 대가·대기 경험치 = growth.ts afterWin 의 알림, 장 시작 것 (wake·stance·escort·heavy·ancient) = pre 뒤 banter 자리
- 다시 하기: 장 시작 플래그로 되돌아가므로 그 장에서 처음 본 안내는 다시 나온다 (회상과 같음, 괜찮음)
- 시뮬레이터·원작판 영향 없음 (대사만)

## 4. 순서 제안
1. 그릇 (tips.ecs·tip()·설정) + 1장 안에 나오는 것 (wake·counter·zoc·flank·promo) — 첫 장에서 바로 효과를 본다
2. 상성 묶음 (undead·resist·caster·arrow·heavy) — 25-2 와 짝
3. 나머지 (stance·tired·foeRest·escort·down·bench·ancient)
4. 손으로 1~10장 해 보며 빈도 조절 (한 장에 둘이 많은지)
