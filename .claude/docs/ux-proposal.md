# UI·진행 틀 평가와 개선 제안 (U2, 2026-10-14)

근거: `ux.md` (U1 실기 관찰·차이표). 승인된 항목만 U3 에서 구현한다.
판 구분 원칙 (editions.md 결정 2026-10-12): **원작판 = 원작 그대로, 편의 기능은 개선판만**. 아래 "공통" 은 두 판이 같이 쓰는 화면 틀이다.
비용: 소 = 표시·설정 / 중 = 새 창·흐름 몇 개 / 대 = 화면 구조 변경.

## 총평
- **화면이 둘로 갈라져 있다.** 타이틀·정비 화면은 원작 그림을 640×480 통째로 확대해 원작과 똑같은데,
  전투 화면만 창 전체 캔버스 + 어두운 반투명 DOM 창(위 바·카드·메뉴·대화창·결과 창)이라 다른 게임처럼 보인다. 사용자 기대("UI 디자인 통일") 의 핵심이 여기다.
- 필요한 원작 그림은 이미 다 있다: tactics 창틀 (camp-bg 에 쓰는 ECPMAI), FRTWND 9조각 창틀·FRTBTN 글자 버튼 (comma·basic·speak),
  ECLIPSE.STA 전투 부품 (커서·모서리 괄호·대상 틀·디더·진영 표시), OTH 「GO!! GO!!」, FULLSOFT 원작 글꼴. 정비 화면 확인창(`camp.ts` confirm)이 이미 원작 창 모양.
- 원작 조작은 단순하고 일관된다 (왼쪽 = 고르기, 오른쪽 = 한 단계 뒤로, 모든 창이 같은 모양). 반대로 정보는 거의 안 보인다
  (마우스 올림 정보 없음, 턴 표시 없음, 피해 예측 없음, 저장은 정비 화면에서만, 패배 = 1장으로). → 앞은 두 판 모두 지키고, 뒤는 개선판에서만 채운다.

## 질문과 결정 (2026-10-14 사용자)
- **Q1 원작판 스크롤** → **결정: 끌기·방향키 허용**. 확대·축소는 원작판 없음, **개선판은 가능** (28번)
- **Q2 화면 확대 방식**: 640×480 을 창에 꽉 맞춤 (정수배 아닐 때 약간 흐림) / 정수배만 (선명, 작은 창에서 여백 큼). 추천: **꽉 맞춤 + 픽셀 보간 끔** (타이틀·정비와 같음) → **결정: 딱 맞춤** (정수배 아님)
- **Q3 원작판 저장**: 원작대로 정비 화면 수동 3칸만인가, 웹 특성상 장 클리어 자동 저장(지금의 이어하기)도 남기나? → **결정: 둘 다**
- **Q4 원작판 시스템 → 알림**: 무엇을 켜고 끄는지 미확인. → **결정: 창은 두고 DOSBox 로 확인될 때까지 동작 없음**
- **Q5 개선판 맵 창 크기** → **결정: 원작판 9×8 그대로, 개선판은 넓게 + 창틀 유지** (27번 안)
- **Q6 (사용자 추가)** 개선판 미니맵, 켜고 끌 수 있게, 아군·적·중립 표시 (29번)

## 2차 결정과 설계 (2026-10-14 사용자 → 설계)
- **27 반응형** (사용자: 창 크기가 어떻든 맞게): 배율 s = min(창 너비/640, 창 높이/480).
  - 원작판: 640×480 고정, 남는 곳 검은 띠.
  - 개선판: 논리 화면 = (창 너비/s, 창 높이/s) → 한쪽은 640 또는 480, 다른 쪽이 늘어 창을 꽉 채운다. 가로로 늘면 위·아래 띠를 가로 반복 구간으로,
    세로로 늘면 기둥을 세로 반복 구간으로 늘린다 (여신 기둥 y 219~269 옷자락, 악마 기둥 y 281~322 불꽃 — 시안 확인). 맵 창 = (너비−136)×(높이−96).
    창(명령·확인·대화)은 논리 좌표라 화면이 커져도 같은 크기, 화면 밖으로 안 나가게 자리를 잡는다.
- **30 위 띠 (개선판)** — 원작 띠 = 가운데 크림색 제목 칸 + 양옆 장식. 그 구조 안에 넣는다:
  - 제목 칸: "3장 · 지하 신전". 띠 버튼에 마우스를 올리면 제목 칸 글자가 그 버튼 설명으로 바뀐다 (정비 화면 도구설명 칸과 같은 방식, 떠 있는 툴팁 없음). 적 차례엔 제목 칸이 붉은 빛
  - 제목 칸 바로 왼쪽: 턴 패 (작은 크림 패, "4턴" + 차례 글자 아군 파랑·적 빨강·NPC 초록)
  - 양옆 장식 위: 원작 글자 버튼 (ECPBUT). 왼쪽 [목표] [턴 종료], 오른쪽 [위험] [지도] [메뉴]. 자리가 모자라면 순위 낮은 것부터 메뉴(시스템 창)로 옮긴다
  - 아래 띠: 왼쪽 = 가리킨 칸 지형 패, 오른쪽 = [뒤로] (터치용, 오른쪽 클릭과 같음)
  - 원작판 띠: 제목만 (원작 그대로)
- **31 대화창 (개선판)** — 원작 speak 틀 (가운데 장식 유지, 양옆만 늘림), 너비 = min(맵 창 − 24, 600), 맵 창 아래쪽에 붙임 (맵 가운데를 가리지 않게).
  - 원작의 "위 A · 아래 B 두 칸" 구조를 살려 두 칸: 위 칸 = 왼쪽 정렬·초상 왼쪽, 아래 칸 = 오른쪽 정렬·초상 오른쪽. 화자마다 칸이 고정돼 누가 말하는지 위치로 보인다. 지금 말하는 칸은 밝게, 다른 칸은 흐리게. 세 번째 화자는 오래된 칸을 바꿈
  - 창 높이를 줄이려고 초상(96×111)은 창 위로 조금 튀어나오게 (창 안쪽 높이 = 이름 + 3줄)
  - 글자는 한 자씩 (원작보다 빠르게), 클릭 = 다 보이기 → 다음 클릭 = 넘김, Ctrl 누르고 있기 = 빨리 넘김, Esc = 장면 넘기기
  - 원작판 대화: 원작대로 448×164 두 칸 (위·아래), 한 자씩
- **22 결과 창 / 24 진로선택** — 원작 팝업 그대로 따른다: comma 창 (주황 제목 띠·크림 바탕) + ECPBUT 글자 버튼, 맵 창 가운데.
  - 22: 개선판 승리 「승 리」 창 = 걸린 턴·쓰러진 동료·보조 목표 몇 줄 + [다음 장][다시 하기][타이틀로]. 패배 「패 배」 창 = [다시 하기][정비 화면][타이틀로]. 원작판은 결과 창 없이 원작 흐름
  - 24: 「진로선택」 창에 원작 순서 버튼 3개 (암흑동굴·혼탁한호수·옛 신전). 개선판은 그 아래 설명 칸 (버튼에 마우스·초점 → 그 길의 목적 한 줄, S2 1번 문구) + 고른 뒤 결정·취소 확인
- 구현이 끝나면 원작 시스템 → 알림이 무엇을 켜고 끄는지 DOSBox 로 확인한다 (Q4 뒤처리)
