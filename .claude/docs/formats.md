# 원작 파일 포맷 (확정된 것만 기록)

## FRT 이미지 컨테이너 — 확정
파일 확장자 무관. 시그니처 `FRT`(일부 `FGT`, 예: ECP03.ECP). 모든 정수 little-endian.
```
파일 헤더 (45B): "FRT" + 이름[40] ('9'로 채움) + u16 count
항목 × count:
  "FRT" + 이름[40]           43B
  u16 a (항상 1)  u8 hasPal (항상 1)  u16 w  u16 h  u32 size   11B
  팔레트 768B (hasPal==1): VGA 6비트 RGB ×256 → ×4 해서 8비트로
  픽셀 데이터 size B: PCX식 RLE — b>=0xC0 이면 (b&0x3F)회 다음 바이트 반복, 아니면 리터럴. w*h 바이트 인덱스.
```
- 항목마다 자체 팔레트가 있다. **투명색 = 팔레트 255번** (흰색), 스프라이트 시트의 프레임 구분선 = 12번 (빨강).
- 같은 포맷이 아닌 것: `FRTWND`/`FRTBTN` 시그니처 (`ECPBAS/BUT/COM/LEV/MAG/MAI/SPE.ECP`, `MAIN.ECP`) = UI 창/버튼 정의, 구조 미분석.

## ECLIPSE.LML 스테이지 맵 — 확정 (`tools/stage.py`)
레코드 2000B × 43 (스테이지 n = 레코드 n-1).
```
+0  u16 0, u16 614, u16 타일수, u16 타일W(56), u16 타일H(48), u16 1, u16 맵W, u16 맵H
+24 원본 타일셋 파일명 ("DDT01.FGT")    +36~99 공통 상수(의미 미상)
+100           레이어1 W*H u8 : 타일 번호
+100+W*H       레이어2 W*H u8 : 0 평지 / 2 숲·바위 / 4 절벽 (추정: 장애물 등급)
+100+2*W*H     레이어3 W*H u8 : 3~6 지형 종류 (추정, 6 = 절벽·밀림)
```
타일 이미지 = `ECPnn.ECP` 의 마지막을 제외한 시트들. 시트당 11열, 타일 (1+57c, 1+49r) 위치에서 56×48 잘라냄, 시트 순서대로 번호 매김. 마지막 시트는 미니맵.

## ECLIPSE.FNT 대사 — 확정
[u16 길이][CP949 문자열] × 440. 순수 텍스트만 있음. 화자·순서·트리거는 파일에 없음 → EXE 하드코딩 추정.

## ECLIPSE1/2.PAD 유닛 종류 표 — 부분 확정
u16 개수(111) + 레코드 118B × 111. 이름 시작 b = 8+i*118. 이름 CP949 10B, 이후 u16 필드 (b 기준): +10 id, +12 초상화, +16 직업?, +24 레벨, +26 HP, +30 MP, +34 미상, +42 공격, +46 방어, +50 이동력. 값이 그럴듯해 [근사 확정]. `tools/units.py`
0~28 주인공 계열(일부 전직 전/후 중복), 29~91 일반 적·몬스터, 92~110 보스·NPC.

## ECLIPSE.MAD 마법 표 — 확정 (`tools/tables.py`)
u16 개수(74) + 레코드 24B. 필드(u16, 레코드 기준): +0 계열, +2 이름 CP949 10B, +12 id, +14 사거리(0~3, 0 = 자기 주변?), +16 범위(0 단일 / 1 / 2 광역), +18 효과 종류, +20 위력, +22 MP 소모.
- 계열 0~8 [추정, 마법 이름 기준]: 빛, 어둠, 바람, 물(얼음), 불, 땅, 소환, 노래(사거리 0·광역 2), 기원
- 효과 7 = 공격 피해 (위력 70~200, 100 기준 % 로 추정). 효과 0 = 회복 (위력 10~40).
  나머지는 상태 이상·강화로 추정, 미확정: 1 개선곡, 2 광경·빙벽·정화·안신곡, 3 질풍술·천둥, 4 마법진, 5 중화술, 6 소성술·회신술, 8 화망·공포, 9 빙봉술·직조·중력, 10 석결술, 11 봉인술, 12 부독·악마키스(독), 13 풍미술·안면곡, 14 월지애·불사조·성가(부활?), 15 유암공간·마귀의시

## ECLIPSE.EAD 장비·도구 표 — 부분 확정 (`tools/tables.py`)
u16 개수(182) + 레코드 30B. 필드(u16, 레코드 기준): +0 분류, +2 세부 종류, +4 이름 CP949 10B, +14 id(1부터), +16 f1, +18 f2, +20 f3, +22 kind, +24 value, +26 x1, +28 x2.
- 분류 0 = 무기 (id 1~104, 세부 1~18 = 무기 18종류), 1 = 방어구 (105~142, 세부 19~23 = 5종류), 2 = 도구·장신구 (143~182, 세부 24~30). 박스 표기 수치와 정확히 일치.
- kind 3 = 공격 보정?, 4 = 방어 보정?, value = 주 수치. x1·x2 = 부가 능력치 추정. f2 = 무기만 1 (장착 조건?). 세부 30(지도·보석류)은 kind 0/1/2 등 다양 — 미확정.
- 다음 할 일: 세부 종류 1~30 의 이름 정하기(대표 아이템 이름으로), kind 0/1/2 의미, x1/x2 가 어느 능력치인지. 유닛 표(PAD)의 장비 필드와 대조하면 확정 가능.

## 유닛 애니메이션 ECPnn.MOV / FIG / MAG — 확정
유닛 종류 i (0~103) → `ECP{i//10:02d}.MOV` 의 항목 i%10. 시트 안에 57×49 간격, 9열.
MOV 13프레임: 0~2 아래(정면) 걷기, 3~4 위, 5~6 왼쪽, 7~8 오른쪽, 9~12 피격·쓰러짐 계열.
FIG = 공격 동작 8프레임 정도, MAG = 마법 시전 (같은 인덱싱, 세부 미분석).
`ECLIPSE.SHA` 104장 = 유닛 정지 아이콘 (56×48).

## 효과음 FVT — 확정 (`tools/voc.py`)
파일 안의 "Creative Voice File\x1a" 위치마다 VOC 하나. 블록1 = 8비트 PCM, rate = 1e6/(256-tc). 22222Hz 모노.
ECLIPSE1.FVT 112개, ECLIPSE2.FVT 74개, ECPANI 15, ECPMARK 2. 모두 3초 이하 효과음. **배경음악 없음** (원래 CD 오디오 트랙이었을 가능성, ISO엔 없음).

## 미확인: 스테이지별 적·아군 초기 배치, 이벤트 스크립트
데이터 파일에서 못 찾음. EXE의 `TroopsData` 관련 코드/테이블로 추정 → 역분석 단계 과제.

## 기타 시그니처 (미분석)
- `FAT   ` : `ECPTIT.FAT`(12MB), `ECLIPSE1~3.FAT` — 애니메이션 추정 (EXE에 `fxFATImageDC`)
- `FMT2` : `ECLIPSE.FMT`
- `FULLSOFT.FNT` : 한글 비트맵 폰트 추정 (리메이크에 불필요)
- `*.SAV` : 세이브 (3791B, 사용자 실제 세이브 2개 보유)
- `ECLIPSE.BAD` 300B × 129 레코드 (52종 고유) — 전투 애니메이션 정의 추정, 미분석

## ECP.EXE
MZ 16비트, Borland C++ 1994. 사운드 Info-Sound TCSND/VOICE 드라이버. 클래스명 단서: `TroopsData`, `LxAiDecide`, `LxAiSearch`, `LxMapData`, `fxChineseDC`.
EXE가 여는 파일명 목록은 오프셋 0x5cd0c~ 근처 문자열.
