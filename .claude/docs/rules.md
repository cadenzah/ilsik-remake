# 게임 규칙

표기: [확정] 원작 분석으로 확인 / [근사] 시험판용 임시값

## 원작 설정 (박스 뒷면 기준)
13종족, 190여 직업, 등장인물 100명+, 무기 18종류 104개, 방어구 5종류 38개, 도구 6종류 40개, 마법 9종류 74개. 전투 맵 43개.

## 전투 (시험판 [근사])
- 턴제 [근사]: 아군(일행) → NPC → 적 페이즈. 원작은 라운드마다 민첩·HP·피로 키 순서로 모든 유닛이 섞여 행동 (formats.md "전투 루프")
- 조종 [확정]: 플레이어는 일행(부대 0)만. NPC 부대는 같은 편 컴퓨터 조종 (초록 받침, 카드에 "NPC (자동)"), 적과 같은 AI·부대 상태 규칙
- 이동: 격자 4방향, 이동력 MOV 칸. 비용: 레이어2 0 → 1, 2 → 2, 4 → 통행 불가. 같은 편은 통과 가능(정지 불가), 적은 통과 불가
- 능력치 [확정]: PAD 기본값 + 장비 보정 (formats.md EAD). ATK = 역량, DEF = 방어. 정신·민첩은 표시만 (원작 MP 없음, 마법은 피로 소모)
- 공격: 사거리 기본 1 (화살병 1~2), 피해 = max(1, ATK − DEF×0.7) ±15%, 명중 100%, 반격 없음
  (2026-10-12 능력치 필드 정정+장비 반영 후 1장: 아리크스 역량16/방어15 → 잡몹에 8 주고 4 받음, HP 20)
- 적 행동 여부 [확정]: 부대 상태 (formats.md) — 0 행동, 1 경계(이동력+1 안에 일행 또는 피격 시 0), 2 대기, 3 이동력 0, 4 숨김. 턴 시작 이벤트로 출현·기상
- 적 대상 고르기 [근사]: 처치 가능 대상 > 기대 피해 큰 대상 순, 없으면 최근접 아군에게 접근
- 캠페인 플래그(npc19)는 장 연결 전까지 켜 둠
- 패배: 아리크스 사망. 승리: 적 전멸 (원작 기본도 같음 [확정]. 장별 호위 패배·보스 처치 승리·목표 칸 도달 승리는 formats.md "전투 승패 조건")
- 경험치·레벨업·회복 없음 (시험판)
