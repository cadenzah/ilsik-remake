## 전투 (시험판 [근사])
- 턴제 [근사]: 아군(일행) → NPC → 적 페이즈. 원작은 라운드마다 민첩·HP·피로 키 순서로 모든 유닛이 섞여 행동 (formats.md "전투 루프")
- 조종 [확정]: 플레이어는 일행(부대 0)만. NPC 부대는 같은 편 컴퓨터 조종 (초록 받침, 카드에 "NPC (자동)"), 적과 같은 AI·부대 상태 규칙
- 이동: 격자 4방향, 이동력 MOV 칸, 칸마다 비용 1. 통행 [확정, 124e:2d08·124e:5039·20ec:a5e0]: 레이어2 값 ≤ 유닛 이동방식 (1 평지·2 숲·4 비행) 이면 통과, 이동방식 3(물) 은 레이어2 3 칸만. 마스크(0/1) 위를 범람 35ae:1253 (이동력+1 걸음, 출발 칸 포함). 같은 편은 통과 가능(정지 불가), 적은 통과 불가. (2026-10-15 전까지 웹은 숲 비용 2·물 통과로 근사했음)
- 능력치 [확정]: PAD 기본값 + 장비 보정 (formats.md EAD). ATK = 역량, DEF = 방어. 정신·민첩은 표시만 (원작 MP 없음, 마법은 피로 소모)
- 공격 [확정, 두 판 공통 — 개선판은 6단계에서 재검토]: 아래 "원작 전투 공식". 1장: 아리크스 → 애수인 12, 애수인 → 아리크스 1 (최소값)
- 적 행동 여부 [확정]: 부대 상태 (formats.md) — 0 행동, 1 경계(이동력+1 안에 일행 또는 피격 시 0), 2 대기, 3 이동력 0, 4 숨김. 턴 시작 이벤트로 출현·기상
- 적 대상 고르기 [근사]: 처치 가능 대상 > 기대 피해 큰 대상 순, 없으면 최근접 아군에게 접근
- 캠페인 플래그(npc19)는 장 연결 전까지 켜 둠
- 패배: 아리크스 사망. 승리: 적 전멸 (원작 기본도 같음 [확정]. 장별 호위 패배·보스 처치 승리·목표 칸 도달 승리는 formats.md "전투 승패 조건")
- 휴식 [확정 20ec:038e]: HP += int(최대HP×0.1+2) (최대HP 까지), 피로 −= min(30, 피로). 원작판 = 움직이기 전 취소(Esc·우클릭·"휴식" 버튼) → "휴식?" 예 → 차례 끝.
  개선판 = 이동·공격 없이 차례를 마치면 자동 (대기·턴 종료). AI 는 피로 > 70 이면 휴식 [추정, 20ec:abe1 세부 미분석]
- 원작판 조작 [확정]: 유닛을 눌러 명령창 → 이동/전투(제자리)/취소. 이동 고르면 범위 표시 → 칸 → 명령(전투/대기). 개선판은 차례가 오면 이동 범위 바로 표시
