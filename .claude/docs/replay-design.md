# 다시 하기·진엔딩 설계안 (S2 제안 6, S3c) — 개선판만

근거: story-proposal.md 6번 상세 + 결정 (재구성까지, 이어받기 = 장비·도감만). 지금 있는 것: `save.ts` 판별 진행 저장
(`next` 이어하기 장, `cleared[]` 클리어한 장과 그 장 시작 때 상태 `at` → 타이틀 "장 선택"으로 다시 하기, 진행엔 영향 없음).

## 1. 분기점 저장 (자동)
- 9장(진로 선택 직전 장)을 클리어하면 그때 상태(일행·소지품·장비·플래그)를 `progress.branch` 에 남긴다. 새로 시작해서 다시 9장을 깨면 덮어쓴다.
- 엔딩에 닿으면 `progress.endings` 에 그 루트(A/B/C)를 더한다.

## 2. "다른 길로" (타이틀 메뉴, 엔딩을 1번 이상 본 뒤)
- 루트 3개 중 하나를 골라 그 루트의 10장대 첫 장부터 시작. 상태 = 분기점 저장 그대로 (레벨·능력치·일행·플래그).
- 이어받기 = 장비·도감만 (결정): 엔딩 때 장착하던 무기·방어구와 소지 장비류를 분기점 상태에 더한다.
  열쇠 도구(깨진금괴 180·요정피리 168·고대은화 179)는 이어받지 않는다 → 루트 조건(13장 수호자·21장 강화)이 그 판의 선택으로만 갈린다.
- 이어하기 기록(`next`)은 새 판으로 바뀐다 (이전 판은 엔딩이 끝난 상태라 잃을 것이 없음).

## 3. 장 지도 (개선판의 "장 선택"을 대신)
- 한 화면: 1~9장 한 줄 → 세 갈래 (A·B·C 루트 순서표대로) → 36~43장 한 줄 → (진엔딩 조건이 차면) 숨은 장.
- 가 본 장 = 장 카드(장소·목표)와 함께 밝게, 누르면 지금처럼 다시 하기 (기록용, 진행엔 영향 없음). 안 가 본 장 = 자리만 "?".
- 찾은 조건 사건 표시 (판을 넘어 누적, `progress.found`): 13장 수호자 합류 · 21장 수호자 강화 · 27장 흑기사 · 36장 루이스 귀환 · 38장 소피아 합류.
  못 찾은 사건은 "?" 로 개수만 → 무엇을 놓쳤는지 알게 한다 (조건은 이미 보조 목표 창에 나온다).

## 4. 진엔딩 (세 루트를 모두 클리어하면)
- 숨은 장 + 진엔딩 에필로그. 숨은 장 맵은 원작 맵을 다시 쓰고, 적·아군 배치만 개선판 데이터(`content/remake`)로 새로 둔다.
- 후보 (확인 필요, 아래 질문 1):
  - 숨은 장 「반란의 밤」(10여 년 전 회상): 레스다·크란·상지스(유닛 없음 → 원작 기사 계열 유닛에 이름만)가 갓난 쌍둥이를 데리고 아도 왕성을 빠져나가는 탈출전 (37장 같은 도달 승리).
    37장 크란의 설명과 에필로그를 잇고, 레스다를 다시 플레이할 수 있다.
  - 숨은 장 「레스다의 과거」: 레스다가 아리크스를 기르게 된 사연 (회상 대화 위주, 전투 1회).
- 진엔딩 에필로그: 일반 에필로그 뒤에 덧붙이는 장면 (예: 아리크스·아티스가 아도 왕성에서 반란의 밤에 잃은 것을 되찾는다, 카론의 정체 암시 회수).

## 5. 세 루트의 정보 나누기 (재구성 범위, 질문 2)
- 지금(S3b 뒤): 루트마다 핵심 정보(사바카 전설·세뇌 소문·쌍둥이 복선)를 다 알려 주고, 루트 고유 사건만 다르다. 한 루트만 해도 이야기가 닫힌다.
- 더 나아간 안: A = 크란과 정체, B = 소피아와 제관의 세뇌, C = 고대 병기와 수호자 쪽 설명을 그 루트에만 두고, 진엔딩 숨은 장에서 합친다.
  세 루트를 다 할 이유가 커지지만, 한 루트만 한 사람에게는 빈 곳이 생긴다.

## 6. 도감 (질문 3)
- 지금 없음. 작은 안: 만난 인물·적(유닛 종류)과 손에 넣은 도구를 판을 넘어 기록하는 목록 화면 (초상화·능력치·설명 한 줄). 기록 = `progress.seen`.

## 구현 순서 (승인 뒤)
1. save.ts: branch·endings·found·seen 기록, "다른 길로" 시작 (이어받기 필터) — 원작판은 그대로
2. 장 지도 화면 (title.ts 의 장 선택을 개선판에서 대체)
3. 도감 화면 (승인 시)
4. 숨은 장: 배치 데이터 형식(`content/remake/battles/*.json`, 원작 레코드 덮어쓰기) + 대본 + 진엔딩 에필로그

## 결정 (2026-10-13 사용자)
1. 숨은 장 **2개**: 「반란의 밤」(탈출전) + 「레스다의 과거」(회상 대화 위주, 전투 1회). 세 루트 모두 클리어 시 열림, 뒤에 진엔딩 에필로그.
2. 루트 정보 **나눔**: A = 크란과 정체, B = 소피아와 제관의 세뇌, C = 고대 병기와 수호자. 진엔딩 숨은 장에서 합친다.
