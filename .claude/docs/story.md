# 원작 스토리 분석 (S1)

출처: `scenes.json` + `dialogue.json` (EXE 하드코딩에서 추출, formats.md "대화 장면"). 요약 도구 `python tools/story.py [script [장…]|stats|routes]`.
장소명은 대사에서 읽은 것 [대사], 대사에 없으면 [추정]. 대사 수 = 초상화 대화 한 칸 = 1줄.

## 뼈대
- 무대: 아모스 대륙. 아도 제국(마군 제국)의 재상 크리스도프와 제관(음마도사)이 10여 년 전 반란으로 왕위를 빼앗고,
  고대 병기(현자의 돌·무자의 책·빛의 갑옷·용자의 검)를 모아 고대 사신 사바카의 봉인을 풀려 한다.
- 주인공 아리크스: 레스다가 기른 청년. 정체 = 아도 제국 왕의 쌍둥이 중 하나, 성전 기사의 피 (37장 크란이 밝힘). 쌍둥이 동생 = 아티스.
- 큰 흐름: 바하라무성 구원 (1~6) → 고신전에서 레스다 사망·일행 흩어짐 (7~9) → **9장 후 진로 선택 (루트 A/B/C)** →
  각 루트로 동료 재결집하며 마군 제국 진입 (10~35) → 사바카 성 공통 종반 (36~43) → 사바카 재봉인 엔딩.
- 진로 선택은 조건 분기가 아니라 메뉴 3택 (선택지 문구는 그래픽인 듯, 미확인). 한 판 = 28~29전, 43장은 세 루트 합.

## 연출 특징
- 장면은 전투 전 (상황 설명) / 전투 중 트리거 (보스 사망 등 5곳) / 전투 후 (합류·정보) 세 시점뿐. 전투 중 연출은 거의 없다.
- 대사량이 앞쪽에 몰림: 1~9장 평균 12줄, 10~35장 루트 전용 장 평균 6줄 (1~2줄짜리 장 7개: 21·23·24·28·30·31·34), 36~43장 평균 7줄.
- 같은 장면의 루트별 사본이 많다 (16장 3벌, 비왕 고백 27/32/33, 페니·혜유 재회 21/23, 성전기사·크란의 사바카 설명 26).
- 선택·조건 연출: 9장 금괴 선택 → 13장 수호자 (C 만), 19장 용왕 생존 → 36장 루이스, 27장 아리크스 빈사 → 흑기사, 38장 소피아 생사.
  이 중 플레이어가 결과를 미리 알 수 있는 것은 없다 (복선 대사 없음).
- 번역 흔적: 이름 흔들림 (퍼스널/파시노, 아리크스/아크리스/아리크리, 아티스/마티스, 제관/음마도사), 띄어쓰기 오류. 쓰이지 않는 사본 줄 다수 (formats.md).
- 엔딩 대사에 고대 병기 4종이 나오지만 이야기에서 다룬 것은 빛의 갑옷뿐.
  다만 데이터에는 넷 다 있다: 아리크스 2차(#1) 장비 = 용자의검(58)·빛의갑옷(114), 38장 클리어 보상 무자의책(148, 합류 소피아 #28 장비), 39장 보상 현자의돌(169) → 37장 성검 = 용자의 검으로 보임 (개선판 대사는 이 배치를 따름)
